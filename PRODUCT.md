## Stack

GitHub profile README: GitHub-flavored Markdown plus image assets (SVG/PNG) committed in this repo or hot-linked. GitHub strips CSS, scripts and iframes from Markdown; SVGs render through `<img>` (camo proxy), so they cannot load external fonts or resources and must embed or outline their type. Light/dark variants switch with `<picture>` + `prefers-color-scheme`.
