## Direction contract

THESIS: The profile is a jazz session sleeve, not a dashboard. It refuses the category default: terminal window hero, stat cards, badge walls, contribution graphs.

OWN-WORLD: One flat spot field in marigold (taken from the avatar's ground) printed with one ink black; cream only for reversed type. Extra-condensed heavy sans caps (Archivo, width 62, black) set at a shared slant, thin ink rules at the same angle, the avatar as a duotone (ink + spot) cropped hard into one corner. No gradients, no shadows, no icons.

STORY: Visitor sees the sleeve and Fango's name, reads one line of who Fango is, then the back-cover track list of projects they can open, then a one-line `npx fangge` and the hex sign-off.

Below it, markdown bio, then the track list strips (each a link).
